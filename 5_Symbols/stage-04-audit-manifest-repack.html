Audit Manifest & Repack

Generates lasso_reduction_manifest.json detailing exact reduction tallies, rule breakdowns, and node mapping, then archives the sanitized directory into a deployable, compressed .tar.gz ready for support dispatch.

Dual-Manifest Architecture

Security vs. Support Manifests

When the reduction engine packages the output, it creates two dedicated manifest files:

1. lasso_reduction_manifest_security_donotshare.json

Internal SecOps Only (CONFIDENTIAL): Retains exact unredacted matched pattern samples, line references, and the real-to-pseudonym IP mapping table for SOC 2 / ISO 27001 forensics. Never shared externally.

2. lasso_reduction_manifest_support.json

Vendor Support Safe: Bundled inside the sanitized archive and output directory. Stripped of all plaintext credentials, tokens, hashes, and internal IP mappings. Proves sanitization without leaking secrets.

Safe Gzip Tarball Repacking

edb_lasso_redacted.tar.gz

The sanitized files are bundled exclusively with the support-safe manifest into a standard gzip/bz2 tarball. The resulting bundle maintains the exact internal directory hierarchy expected by EDB portal intake parsers. 

# Repack command executed automatically
python3 lasso_redact.py -i raw.tar.gz -o output/bundle.tar.gz
