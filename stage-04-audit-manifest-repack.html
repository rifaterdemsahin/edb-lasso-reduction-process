Pipeline Stage 04 of 04

Audit Manifest & Repack

Generates lasso_reduction_manifest.json detailing exact reduction tallies, rule breakdowns, and node mapping, then archives the sanitized directory into a deployable, compressed .tar.gz ready for support dispatch.

The Audit Trail Manifest

lasso_reduction_manifest.json

Every secret detection is logged with its rule ID, file origin, and category. This provides compliance teams (SOC 2, PCI-DSS) verifiable proof that no credentials or private subnets were dispatched externally.

  • Total Redactions Count
  • Category & Rule Tallies
  • Deterministic IP Mapping Table
  • SHA-256 Output Integrity Hash

Safe Gzip Tarball Repacking

edb_lasso_redacted.tar.gz

The sanitized files are bundled alongside the audit manifest into a standard gzip tarball. The resulting file maintains the exact internal directory hierarchy expected by EDB portal automated intake parsers. 

# Repack command executed automatically
tar -czf lasso_sanitized.tar.gz \
    -C sanitized_bundle .
