Deterministic IP Mapping

Maps internal IP addresses (e.g. 10.0.12.45) to consistent aliases (PSEUDO_IP_NODE_01) preserving PostgreSQL cluster topology and node relationships without exposing private internal networks.

Naive Masking (Breaks Diagnostics)

Replacing all IPs with generic [REDACTED_IP] destroys node correlation. Engineers cannot tell which standby connects to which primary, or which node triggered failover in repmgr or EFM. 

# All nodes look identical - Topology is lost!
primary_conninfo = 'host=[REDACTED_IP] port=5432'
barman_host = '[REDACTED_IP]'
standby_1 = '[REDACTED_IP]'
Deterministic Pseudonyms (Safe & Intact)

Our algorithm creates a consistent 1-to-1 pseudonym map across every file in the bundle. Node relationships, replication trees, and backup streams remain 100% analyzable. 

# Relational topology is fully preserved!
primary_conninfo = 'host=PSEUDO_IP_NODE_01 port=5432'
barman_host = 'PSEUDO_IP_NODE_03'
standby_1 = 'PSEUDO_IP_NODE_02'
