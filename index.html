What is EDB Lasso?

EDB Lasso is a multi-platform diagnostic tool developed by EnterpriseDB (EDB), one of the leading providers of PostgreSQL products, enterprise tooling, and 24/7 mission-critical support.

When troubleshooting or debugging complex database environments, getting a complete picture of the system's state is often the most difficult step. Lasso acts as an automated collector that safely gathers configuration details, performance metrics, and system statistics from both the PostgreSQL database and the underlying operating system.

The "Black Box" Flight Recorder

Lasso grabs all the necessary context cleanly and securely so support teams and DBAs can identify and fix the issue without guesswork or iterative delays.

1. Standardizes Process

Eliminates log "ping-pong" between engineers. Instantly bundles standardized system metrics support teams already know how to read.

2. Production-Safe

Zero Data Extraction: Never pulls user data or table rows. Imperceptible overhead on active workloads.

3. Holistic Visibility

Spans OS statistics (CPU, memory, disk) and surrounding tools like Barman, repmgr, and EFM.

4. Direct Support Integration

Integrated with customer tokens for secure, automated uploads straight into EDB's support portal case tickets.

Zero-Leak Assurance

The Lasso Reduction Process

While Lasso does not touch customer database tables, configuration files like postgresql.conf, pg_hba.conf, and barman.conf frequently contain replication passwords, auth hashes, customer portal tokens, and internal network IP ranges.

STEP 01

Ingestion & Unpack

Extracts the EDB Lasso tarball (.tar.gz) or output directory without altering raw file permissions.

STEP 02

Credential Stripping

Identifies and masks passwords in conninfo, MD5 hashes, SCRAM-SHA-256 tokens, API keys, and customer tokens.

STEP 03

Deterministic IP Mapping

Maps internal IP addresses (e.g. 10.0.12.45) to consistent aliases (PSEUDO_IP_NODE_01) preserving cluster topology.

STEP 04

Audit Manifest & Repack

Generates lasso_reduction_manifest.json detailing redaction tallies and produces a sanitized archive.

Running the Reduction PoC via CLI

        

          Integrate the EDB Lasso reduction engine directly into your automated collection scripts or CI/CD pipelines before uploading to EDB Support.
        

      


      

        

          

            
            Sanitize a Mock Diagnostic Folder
          

          
Recursively scrubs configs, pseudonymizes IPs, and creates a manifest in the destination folder:

          
python3 lasso_redact.py \
  -i mock_lasso_bundle \
  -o sanitized_lasso_bundle

        


        

          

            
            Sanitize a Compressed Tarball (.tar.gz)
          

          
Unpacks, reduces sensitive secrets in-memory or in temporary storage, and produces a clean bundle:

          
python3 lasso_redact.py \
  -i lasso_diagnostic_20260916.tar.gz \
  -o lasso_diagnostic_20260916_redacted.tar.gz
