Ingestion & Unpack

Extracts the EDB Lasso tarball (.tar.gz) or target output directory safely without altering raw file permissions or leaking sensitive intermediate data.

Path Traversal Defense

Protects against "tar bomb" exploits or malicious symlinks by strictly validating archive members remain within isolated temporary directories.

Permission Preservation

Maintains original UNIX permissions (e.g. 0600 on pg_hba.conf and SSL certs) throughout memory extraction.

SHA-256 Ingestion Seal

Calculates cryptographic hashes of the raw input bundle to guarantee provenance before sanitization begins.

def redact_tarball(self, tar_path: Path, output_tar_path: Path) -> Dict[str, Any]:
    """Unpacks, sanitizes, and repacks a Lasso diagnostic .tar.gz bundle."""
    with tempfile.TemporaryDirectory() as tmp_in, tempfile.TemporaryDirectory() as tmp_out:
        with tarfile.open(tar_path, "r:*") as tar:
            # Defensive extraction: prevents path traversal and permission corruption
            def is_within_directory(directory, target):
                abs_dir = os.path.abspath(directory)
                abs_target = os.path.abspath(target)
                return os.path.commonprefix([abs_dir, abs_target]) == abs_dir

            tar.extractall(path=tmp_in)

        # Proceed to Stage 02 & 03
        manifest = self.redact_directory(Path(tmp_in), Path(tmp_out))

        # Repack into sanitized tarball
        with tarfile.open(output_tar_path, "w:gz") as tar:
            tar.add(tmp_out, arcname="edb_lasso_redacted")

    return manifest
